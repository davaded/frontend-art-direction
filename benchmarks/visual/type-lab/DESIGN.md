# DESIGN.md

## Visual Direction

- Design stance: Quiet typographic instrument around one expressive working object
- Composition: Family index, central artboard and compact toolbar, property rail; on mobile a compact object precedes text properties, then the family collection
- Dominant: The current artwork and its genuine type shape
- Typography: Compact Sora interface; Newsreader, Sora, and Space Mono are selectable artwork families
- Material: Neutral workspace; the initial Sora 500 study uses rose paper; mint, ink, rose, and sulfur are actual editable artwork palettes rather than page-wide themes
- Geometry: Unframed control rails, one genuinely framed artboard, compact controls and optical grouping before borders
- Motion: Immediate preview; small selection/press transitions; history and final states remain clear with reduced motion
- Scope: Family selection, text, weight, size, leading, alignment, palettes, undo/redo, saved studies, empty-state recovery, PNG export, responsive controls

Large type belongs to the user's specimen, not to compact UI headings. Local candidates do not replace this instrument.
