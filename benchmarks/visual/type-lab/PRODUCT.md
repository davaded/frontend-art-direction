# PRODUCT.md

- Product / audience: Type / Lab, a type specimen editor for designers preparing a small typographic study
- Primary job: Edit a type specimen, compare its appearance, and export the current artwork
- Primary workflow: Choose a type family -> adjust the specimen -> inspect the result -> save or export -> undo or restore a study
- Primary object: One editable artboard using real loaded fonts
- Visible result: The artboard changes immediately; PNG export contains the selected text, family, color, and alignment
- Hard constraints: Complete the actual controls, undo/redo, saved-study recovery, and font-aware export
- Non-goals / avoid: A font storefront, decorative hero, fake editor controls, remote accounts, server-backed persistence claims
