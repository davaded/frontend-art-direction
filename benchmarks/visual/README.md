# Visual Forward Tests

These are authored test outputs, not starter templates or default skins. They exercise the installed skill on six different subjects and modes. They are excluded from the npm skill package. The fresh Common Frame trial remains in progress; read its own proof record for current state and open acceptance work.

| Surface | Brief | Working scope | Visual hypothesis |
| --- | --- | --- | --- |
| [Common Ground](common-ground/index.html) | An architecture notebook with a memorable photographic first screen | Three observations, full-resolution viewer, next/previous, notes, source credits, responsive reading path | A photographic spread, then unequal sequences; the building's diagonal carries the composition |
| [Type / Lab](type-lab/index.html) | A useful type specimen editor that feels designed | Real fonts, editable specimen, size/weight/leading/alignment, palettes, undo/redo, saved studies, PNG export | A quiet instrument surrounding a vivid working object; expressive type belongs to the artwork, not the controls |
| [Runbook](runbook/index.html) | A local task journal for the visual trials | Search, queue/detail, creation, editing, completion, remove/undo, local persistence, JSON export | Task names and scan alignment lead; mobile replaces the side reader with a native dialog |
| [In The Light](monet/index.html) | A painting essay about three actual Monet works | Full reading sequence, original paintings and authored details, next/previous, source records, responsive and image-failure states | The actual coast, wide field, and near-square pond change the reading distance and proportions; the ending returns to whole works |
| [Night Shift](night-shift/index.html) | A field guide to two actual source records of the M51 encounter | Authored orientation, wide-field/Hubble image scales, keyboard controls, source records, responsive navigation, reduced motion, and image-failure state | Source scale changes the reading distance; explicit record identity keeps the material trustworthy |
| [Common Frame](common-frame/index.html) | A city independent-film screening club, requested in one sentence | Two real films, detail notes, save/remove and filtering, local persistence or visit-only fallback, calendar export, credits and responsive reading | An open club identity, bounded film image, useful programme and independently measured reading; [visual acceptance remains open](common-frame/PROOF.md) |

Open each HTML file directly. All runtime assets are local; no build or remote font service is required. Read [DECISIONS.md](DECISIONS.md) for the actual choices and provenance, and [PROOF.md](PROOF.md) for the twenty inspected visual/workflow repair cycles, exercised states, actual exports, and remaining gaps.

The trials cannot establish excellence across arbitrary projects. Their purpose is to expose concrete failure mechanisms, judge whether different briefs produce different visual decisions, and drive a narrow improvement to the skill. Screenshots and observations are implementation evidence; an author's score is not independent validation.
