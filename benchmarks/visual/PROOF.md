## A Skill Failure Exposed By The Trials

Before the adapter repair, the intent `immediate type preview, undo and redo, palette selection; no animated text shaping` selected `shimmer-text` with high confidence. Source scanning also treated array `filter()`, stylesheet links, and a reduced-motion guard as UI motion candidates.

[Before](artifacts/motion-before.json) uses the pre-change adapter, verified identical across commits `8fa1067` and `0f0c603`. [After](artifacts/motion-after.json) uses the repaired adapter on the same intent and project. The repaired result selects no recipe for this unresolved/static preview job. Common English/Chinese negative clauses are excluded, broad terms no longer become recipe IDs through substring matches, and code-only findings are marked `review-needed`. A generic transition does not inherit the project's unrelated modal job. Explicit `--transition` pins remain authoritative. Behavioral regressions cover these paths in the package test command.

This source-routing repair is recorded separately; it is not counted as another rendered visual iteration.

## Image Proposal Attempt

The built-in `imagegen` tool was called with the inspected notebook desktop baseline as the edit target. It returned `model_not_found`: the configured group did not support `gpt-image-2`. No proposal image was produced, selected, or translated. No CLI/API fallback was used. The attempt is not a completed image iteration.

A second proposal attempt used the inspected M51 material as the target for a richer subject-led direction. It returned the same `model_not_found` result, so the Night Shift revision continued through attributable source assets and rendered browser captures rather than pretending a generated proposal existed.

The submitted prompt was:

```text
Use case: ui-mockup. Edit target: the provided 1440x900 actual browser screenshot of Common Ground, an architecture photography notebook. Produce one realistic design revision of this same viewport. The current white serif title loses legibility over bright stairs; tiny white labels are also hard to read. Explore a stronger type-to-photograph relationship and reading hierarchy. Keep the real black-and-white Eye Film Museum photograph identifiable, the architectural diagonal and its material visible, and keep the notebook as the subject. Preserve the header navigation and the beginning of the next reading section. Exact visible identity: Common Ground. Maintain the photography-led, unframed editorial composition; no decorative cards, no dark overlay hiding the architecture, no effects, no new brand or invented claims. Make the title readable through positioning, crop and type proportions rather than adding a blanket overlay. This is a design proposal to translate into semantic HTML and responsive code, not a replacement screenshot or production asset.
```

## Limits And Next Work

Twenty-five rendered visual/workflow cycles are supported here across five briefs. They have different jobs, objects, and compositions, including an ordinary field-guide product surface carried by two real source records of one astronomical encounter. The latest independent review is bounded to the supplied screenshots; it is not a user study or a universal aesthetic acceptance. Full accessibility audits, other browsers, broad multilingual/font coverage, maximum-density data, unavailable-storage recovery, and repeated motion interruption remain unverified. Image-driven divergence still needs a working image provider: the built-in attempt returned `model_not_found` for `gpt-image-2`. These gaps keep the broader research/improvement goal open.
