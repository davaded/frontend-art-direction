# Changelog

## Unreleased

- Added an executable geometry contract with softened structural defaults, corner hierarchy, non-border separation, line-purpose checks, sharp-context exceptions, and hard-edge scaffolding rejection.
- Refreshed the Rare UI reference lens and recipe from live desktop/mobile inspection, including its dark organic shell, asymmetric specimen mosaic, and tiered edge hierarchy.
- Added a dependency-aware `graph` command and queryable repository neighborhoods.
- Added executable design quality gates, scene dials, anti-pattern checks, and implementation checks to `brief`.
- Added a provenance-aware `resource` catalog with trust tiers, license boundaries, and rejection conditions.
- Added a unified `audit` command that connects all reference capabilities to the `Decision / Changed / Proof / Open` response contract.
- Made the full audit the default for every frontend request: all reference lenses are considered, the resource matrix is classified, the reference/build contract is produced, and Motion runs by default.
- Added an internal Transitions.dev motion bridge with pinned-source caching and `Review -> Apply -> Polish` phases.
- Added explicit motion-purpose, cleanup, reduced-motion, and static-fallback guardrails.
- Added role-based reference composition for Rare UI, Beautiful UI, beUI, Transitions.dev, and shadcn/ui, with a maximum four-lens budget and borrow/reject/translate decisions.
- Added `reference-build`: one sentence plus a named reference now produces an implementation-ready visual genome, page plan, component grammar, motion contract, responsive plan, and acceptance gates.
- Added reference fidelity anchors for composition, material/type, and interaction cadence so a named case must be visible in the rendered result rather than only mentioned in prose.
- Kept upstream transition source out of this package; the bridge fetches it only when motion work needs it.
- Added an executable Visual Direction Contract that locks composition, alignment, dominant/counterweight, typography, spacing, surface budget, and AI-default rejection before styling.
- Added `direction` routing plus first-viewport, grayscale, thumbnail, and mobile restaging checks to the audit and smoke suite.
- Added visual treatments for ordinary, product, humanist, stateful, data, and specimen surfaces so adaptive requests still receive an authored visual stance instead of a neutral template.
- Added tiered constraint authority: hard invariants remain protected, while project-owned `DESIGN.md`, inspected references, accepted concepts, explicit user direction, and evidence-backed model proposals can override advisory visual defaults.
- Added automatic `DESIGN.md` authority detection, creative-divergence checks, override records, and a regression fixture in `npm test` so local rules do not silently normalize a project's own design language.
- Fixed unnamed reference handling so supporting lenses cannot masquerade as the primary visual authority in an adaptive build.
- Added an inspected Rewamp UI component-workbench lens, dedicated reference-build recipe, implementation resource entry, mobile re-staging rules, and routing regression coverage.
