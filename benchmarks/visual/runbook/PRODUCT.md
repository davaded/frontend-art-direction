# Runbook

A local task journal for the frontend skill's ongoing visual trials. The initial entries describe this repository's actual work; the journal is a trial product, not a claim that its local dates or statuses are synchronized with project evidence. A visitor can search, select, complete, add, edit, remove/undo, and export tasks. There is no account or server write.

Desktop prioritizes scanning the queue beside a selected task. Mobile prioritizes the queue and opens the same detail in a native dialog. Content may be long, empty, overdue, or completed. The working task and result must remain clear through those states.
